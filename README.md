# 📖 Sobre

Este projeto foi desenvolvido a partir de um desafio do **Frontend Mentor**, plataforma que disponibiliza interfaces criadas por designers para que desenvolvedores pratiquem a implementação de aplicações Front-end utilizando tecnologias do mercado.

O desafio consistiu em reproduzir uma **Landing Page** com tema escuro, buscando a maior fidelidade possível ao layout original, colocando em prática conceitos de HTML semântico, CSS moderno e responsividade.

---

# 🚀 Conteúdos praticados

- ✅ HTML5 Semântico
- ✅ CSS3
- ✅ Flexbox
- ✅ Grid Layout
- ✅ Responsividade
- ✅ Layout Mobile First
- ✅ Hover States
- ✅ Organização de código
- ✅ Boas práticas de desenvolvimento Front-end

# 🎯 Objetivo

Este projeto teve como objetivo aprimorar minhas habilidades em desenvolvimento Front-end através de um desafio do **Frontend Mentor**, praticando a criação de layouts responsivos e a reprodução fiel de um design profissional.

Durante o desenvolvimento, também exercitei conceitos importantes de estruturação semântica, organização de estilos e adaptação da interface para diferentes tamanhos de tela.
